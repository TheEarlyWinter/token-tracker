### 主代理裁定的数据契约

- 初始化先创建 dataDir。schema 迁移必须完整提交。初始化失败时关闭连接，保存 storageError，查询返回可识别的存储不可用错误；不能伪装空内存历史。未传 dataDir 或确实缺 SQLite 驱动时仍支持原内存模式。
- 使用现有 appTimeZone/formatAppDay。日期区间从应用今日日期转为 UTC 日历计算。旧 day 值做一次性应用时区修正，可用 PRAGMA user_version 管理本模块小迁移。
- 保留已部署的 responseId_timestamp 身份格式，避免新代码把旧历史再计数。无 responseId 时从 Agent、稳定 session 身份、时间戳与稳定消息字段生成确定 ID。实时与历史必须得到同一身份。外层 entry.id 仅在时间戳缺失等情况下补充，不能让两个入口对同一条消息使用不同 ID。
- 历史扫描读取 JSONL session header 中的真实会话 ID，不能总用文件名代替。无 responseId 的旧随机 ID 记录，可按 Agent/session/at/目标和返回模型等精确匹配重用或更新 ID。不删除、合并既有行；已存在的重复行留给单独授权处理。
- recordRoute 仅新增返回 true，重复返回 false，SQLite 检查 changes。写失败抛出，扫描事务回滚，不缓存失败进度。
- 复用写语句，扫描按文件或批次事务提交。文件采用追加字节游标。截断后重读，不完整尾行留待重试。只在成功提交后发布游标。不要添加 worker 或后台队列。
- 支持现有扁平消息 usage，兼容项目已经处理的结构化 usage。结构化 input.totalTokens 含缓存读，列表 input 表示未命中；总量不得重复加缓存读。扁平总量回退要包含 cacheWrite。模型对象只能取 modelId，不允许出现 [object Object]。
- provider 精确筛选。model 保持裸 ID（可含斜杠），同时兼容 provider/model 复合筛选，不可无条件按最后一个斜杠裁切。DB 与内存保持相同语义。
- 查询参数只在 queryRoutes 这一入口校验。HTTP handler 只传原始参数并映射错误。分页必须是安全整数，limit 1..500、offset 0..MAX_SAFE_INTEGER，默认 100/0；非法值统一安全 400，不保留 HTTP 拒绝而内部又截断的两套规则。SQL 和内存均按 at DESC、id DESC 排序。
- 非法 range/date/status 返回固定安全 400；存储不可用返回安全 503；其余故障不回显内部路径。保留 summary 不随 status 改变的设计。
- 新旧测试中，r1 必须显式指定合成时间。原重复写入断言 true 应改为 false，先用新契约捕获旧实现红灯。


### 第一轮实施后的主代理阻断复核

- 两个明确不同的 responseId，在同会话同时间下被错误当成旧行复用，总数从应有 2 变为 1。旧行匹配必须限定旧随机 ID 的真实格式，不能匹配任意正常记录。
- 旧扫描保存文件 basename，新扫描读取 header ID；同一条旧消息因会话 ID 改变被再次入库。应传已知旧别名精确匹配，不得全局忽略 session 条件。
- readSessionHeaderId 先 readFileSync 全文件再截 128KiB，而且每条消息重复读取；扫描也先整文件读再截增量。合成 131KB 文件的 10 条消息触发 1.31MB 额外读取。要求真实范围读取、header 缓存和字节计数回归，不能只验证 offset 数字。
- schema 只迁移已知缺列，不能用默认值补齐任意损坏表的全部必填列。
- 独立复查确认历史只扫普通 sessions，漏 subagent-sessions。应仅扩展这两个已知根目录的 JSONL 发现范围，不扩大到其他数据目录，不自行推断子代理实际执行者。
- 无法映射的旧外部会话 ID 或无法确认的旧重复行，不自动合并或删除。必须在交付说明中区分新代码去重与旧数据修复。
