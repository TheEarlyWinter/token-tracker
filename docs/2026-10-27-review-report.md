## 已修复的关键链路

### 1. 重置卡与跨面板交互

- ACK 到达后正确结束等待。统一清理监听和计时器。
- 等待窗口为 400ms。请求带过期时间，并匹配请求 ID。
- document.hidden 为 true、已关闭或请求已过期的页面不接管弹窗。尚未将宿主 lifecycle 可见性接入 ACK 判断。
- 多张卡交替操作不会累积确认事件。一次确认只核销一次。
- 侧板重绘复用原弹窗节点。首次点击等待接管或列表加载时，刷新不会移除正在打开的弹窗。遮罩关闭监听不累积。
- connected 状态刷新保留 header 和按钮，只更新套餐、余额、卡数与额度条。鼠标按下后发生焦点刷新，原按钮不会脱离 DOM。按钮 onclick 使用最新回调，不累积事件。
- 核销只认 HTTP 成功且业务代码明确为 `reset`。未知结果不自动重试。
- 核销后通过独立额度接口强刷。刷新完成或失败后再通知其他视图。
- 核销后的额度请求使用新代次。旧请求不能覆盖新缓存或清除新请求指针。重置卡列表同样隔离旧响应。
- 空额度响应不再显示为已连接。保留正常单窗口、零用量和有效余额响应。

### 2. 日期、筛选与异步显示

- 日期输入补齐“昨天”。DeepSeek 月份按钮同步全局日期。
- 明细旧响应不能覆盖新筛选。关闭详情后，旧响应不能重新打开详情。
- 后台扫描更新会刷新明细，但不无故重置页码。
- DeepSeek 和 Lithos 加载中切换日期，最终采用最新日期。
- 稳定筛选和重复渲染不额外查询账单。
- 今日金额只取真实当日，不拿最后一个有记录日代替。
- 超过 12 个月的自定义区间明确报错。不静默截断。
- 调用详情价格时段和明细日期使用统计时区。
- 本周起点按统计时区的日历日期计算，不使用进程时区的星期。已覆盖 UTC 与上海跨周边界。

### 3. Token 与执行者归因

- 派生统计中的输入使用未命中输入。原始归档保留总输入和未命中输入。
- 缺省总量不重复加入缓存。显式总量优先。
- 缓存命中率统一为“缓存读 / 含缓存的输入”。90 个缓存读、10 个未命中输入显示 90%，不是 100%。
- 同名模型按供应商分别保存执行者用量。总览、执行者和模型筛选使用同一维度。
- 派生缓存版本升为 23。旧版本从归档重建，不改写原始记录。

### 4. 费用与凭据边界

- 费用按供应商和模型分组。不再根据宿主模型列表猜历史供应商。
- 缺少对应供应商价格时标为未定价，不借其他供应商的价格。
- 按币种保存估算小计。缺价或多币种时不制造单一总额。
- DeepSeek 和 Lithos 轮换凭据时清缓存，并隔离旧在途响应。
- 凭据原子写入，权限为 0600。修正已有文件的宽松权限。
- 余额查询使用宿主网络桥。地址仅允许 HTTPS、无 URL 用户名密码、主机在 manifest 白名单内。
- 补齐现有默认余额服务需要的三个主机。没有放开任意主机。
- 非法旧地址保留配置错误状态，不静默改为官方默认地址。
- 本地原生 fetch 使用真实超时信号。
- 移除 Codex 原始账户响应日志。非法 DeepSeek 金额不再伪装成零余额。

### 5. 持久化与故障恢复

- 扫描提交前失败会撤销对应待提交批次，不再永久 BUSY。
- 最终提交屏障失败会报错。内存保留旧成功快照、待恢复屏障和脏桶。
- 同一归档事件重试会再次落盘。未落盘记录不能只因存在于内存就返回伪成功。
- 实时界面去重与归档持久化去重分离。重试不重复累计界面数据。
- 同一 Agent 切换会话时重置会话统计。
- 账本解析缓存包含绝对来源路径，避免不同数据目录串缓存。
- 归档读取失败或损坏导致历史缩减时，拒绝覆盖成功快照。
- 损坏的旧归档保留原位，重启后仍能识别。合法归档迁移和半截尾行恢复保留。
